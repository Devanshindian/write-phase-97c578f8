# listicle

Used by ONE consumer: the architect's shape step (it becomes {{FORMAT_STRUCTURE}} in the structure prompts).

## Structure (the format's signature)
- [ ] **ONE crisp intro (2-4 sentences: who the list is for + how you chose/ordered it). NO long preamble — jump straight into the list.**
- [ ] Optional **buying-intent specs/comparison table above the items** (product/buying-intent only; the sole thing allowed before the list).
- [ ] **Body = the N parallel items** (80%+ of the article), **kept flat — no nested sub-lists inside items.**
- [ ] All supporting blocks (definitions, buying guide, pros/cons, data) go **below the items**, never in front.
