# data-benchmark-report

Used by ONE consumer: the architect's shape step (it becomes {{FORMAT_STRUCTURE}} in the structure prompts).

## Structure (the format's signature)
- [ ] **Big-number headline** — leads with the single biggest number or the dataset scale, never a neutral label. If you can't imagine a compelling headline for a finding, the finding is weak.
- [ ] **Intro (2-4 sentences) states N / dataset size immediately** — what you studied, how big, why it matters.
- [ ] **A numbered key-findings menu up top**, before any detail — the citation menu, and the single most-linked part of the page.
- [ ] **[RIGOR] methodology block — findable, never buried:** a short 2-4 sentence in-page block high on the page, plus a full appendix at the bottom. Load-bearing, not optional.
- [ ] **8-15 distinct findings, one section each** — no two overlap; each carries its own novel number.
- [ ] **Segment findings** (industry / size / region) so one study feeds many citers.
- [ ] Front-load the crunchiest bite-sized stats. Close with takeaways + citation aids (embeddable chart, "cite this study" line).
- [ ] **Publish as a free web page — never a gated PDF** (a form kills the citation).
